Синхронизация (Supabase)

По умолчанию данные хранятся только в этом браузере. Чтобы рисунки и прогресс были на ПК и телефоне одновременно — подключи бесплатный Supabase.

Инструкция: создай проект на supabase.com, выполни SQL из README, скопируй URL и anon key сюда.

Экспорт и импорт

Резервная копия прогресса и задач в JSON. Рисунки хранятся отдельно (IndexedDB) и сюда не входят.

Сброс

Удаляет весь прогресс, задачи и XP. Рисунки в галерее останутся.

О проекте

Путь Художника — учебный трекер для тех, кто рисует «для себя». Без серверов, без регистрации. Работает на GitHub Pages.
